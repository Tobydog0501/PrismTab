隨附自訂義工坊與擴充功能快速入口，讓您隨時隨地掌控每一個細節。

開啟 PrismTab 新分頁

原生小工具規範 (Native Widgets)

擴充功能嚴格遵循原生小工具標準：
• 時鐘與日期 (Clock & Date)
• 搜尋列 (Search Bar)
• 快速導航器 (Quick Navigator / Dock)

進階自訂義模式 (Advanced Customization)

開啟進階功能後可解鎖：
• 自訂小工具工坊 (計數器、REST API 輪詢、HTML/JS 沙盒、IFrame 嵌入)
• 液態光學微調 (毛玻璃模糊、透明度、邊框光澤、SVG 折射噪點)
• 自訂 CSS / JS 即時注入

Chrome 安裝與管理方式

  1. 開啟 Chrome 網址列並輸入 chrome://extensions。
  2. 開啟右上角「開發人員模式 (Developer Mode)」。
  3. 點擊「載入未封裝項目 (Load unpacked)」並選取本資料夾。
  4. 開啟新分頁即可直接使用，隨時可在齒輪圖示中進行深度微調！
